OPS の LINE 部分を
動かすカギを手に入れる

これがあると、OPS ダッシュボードのプレビュー画面で LINE 本文が自動で書かれます。10 分で終わります。

⏱️ 約 10 分 💳 最初は 5 ドル (約 750 円) 🧑‍💻 ターミナル操作 最小
💡
そもそも、このカギは何?

OPS ダッシュボードを開くと、LINE のプレビュー欄に「お客さんに届く文章」が出ます。 その文章を AI が毎回その場で書く 仕組みになっていて、AI に話しかけるための専用の合言葉が必要です。それが API キー。 無いとプレビュー欄に「⚠️ ANTHROPIC_API_KEY が設定されていません」と出てしまいます。

このページを上から順に進めれば、コピペだけで設定できます。途中わからなくなったら、その step のキャプション通りに画面のボタンをクリックしてください。

⚡ 全体の流れ (5 ステップ)
🚪
1. サイトを開くAnthropic のページに行く
 🪪
2. アカウントを作るGoogle でログインがおすすめ
 💳
3. お金をチャージ$5 から (使った分だけ減る)
 🔑
4. カギを発行長い文字列をコピー
 📄
5. パソコンに貼り付け1 行コピペするだけ
📋 詳しいやり方
1
🚪

Anthropic のサイトを開く

下のボタンを押すと、AI の会社「Anthropic」の管理画面が開きます。

🤖
console.anthropic.com を開く 新しいタブで Anthropic の管理画面が開きます
開く →
ひとこと: 普段 Claude とおしゃべりしてる claude.ai とは別のサイトです。今回使うのは console(管理画面) のほうです。
2
🪪

アカウントを作る (またはログインする)

画面に「Sign up (新規登録)」と「Log in (ログイン)」のボタンがあります。

1 初めての人: 「Sign up」を押して、"Continue with Google" をクリック (普段使ってる Google アカウントを選ぶだけ。一番ラク)
2 もうアカウントある人: 「Log in」からログイン
3 初回は "Organization name" を聞かれます。自分の名前や会社名 (例: my-ai) を入れて Continue
ここまで来たら成功:
  • 左に「Dashboard / API keys / Billing / Settings」というメニューが並んでいる
  • 右上に自分のメールアドレス か Organization 名が出てる
3
💳

最初に少しだけお金をチャージする

AI を使うときだけ少しずつお金が減る仕組みです。先に $5 (約 750 円) だけ入れておきます。LINE 文章を 1 回まるごと書き直しても 10 円もかかりません。

画面の流れ:

1 左のメニューから "Billing" をクリック
2 「Add payment method」でクレジットカードを登録
3 "Buy credits" を押して $5 と入力 → 購入
4 (おすすめ) "Auto reload" を ON にすると、残高が減ったら自動で補充されて止まらない
料金イメージ: LINE 全 25 メッセージを一括で AI に書き直してもらっても 1 回 5〜7 円程度。$5 (750 円) チャージで普通の使い方なら 1〜2 ヶ月もちます。
4
🔑

カギ (API キー) を発行してコピーする

いよいよ本番です。長い文字列が表示されるので、その場で必ずコピー してください。

画面の流れ:

1 左メニューの "API keys" をクリック
2 右上の "Create Key" ボタンを押す
3 名前を入れる (例: vivi-club-ops)。何用かわかればなんでも OK
4 "Create Key" を押すと sk-ant-api03-xxxx... という長い文字が出る
5 右の 📋 Copy ボタンでコピー。コピーしたらメモ帳に一旦貼り付けて保管
⚠️ ここが一番大事です。 このカギは この画面を閉じたら二度と見られません。閉じる前に必ずコピー。万が一閉じてしまったら、もう一度「Create Key」で作り直してください (前のは Revoke ボタンで消す)。
5
📄

パソコンに貼り付ける

コピーしたカギを、OPS が読みに行く決まった場所に置きます。ターミナル (黒い画面) を使う方法と、Finder で直接ファイルを開く方法、どちらでも OK です。

🅰️ ラクな方法: ターミナルで 1 行貼るだけ

1 Spotlight (⌘ + Space) で「ターミナル」と打って Enter
2 下のコマンドの sk-ant-... の部分を、Step 4 でコピーした自分のカギに置き換えて、ターミナルに貼り付けて Enter
これを貼って Enter 
cd ~/Desktop/ARTISTORY\ BASE/ViVi/ViVi-Club/Sales/platinum-launch/pm/dashboard
echo "ANTHROPIC_API_KEY=sk-ant-ここに自分のカギを貼る" > .env.local
うまくいった合図: エラーメッセージが出ず、何事もなくプロンプト ($) が戻ってくる。これで保存完了です。

🅱️ ターミナル怖い人向け: Finder で直接編集

1 Finder で ViVi-Club/Sales/platinum-launch/pm/dashboard フォルダを開く
2 ⌘ + Shift + . (ドット) を押すと隠しファイルが表示される
3 .env.local というファイルをダブルクリック (テキストエディットで開く)
4 1 行だけ書く: ANTHROPIC_API_KEY=sk-ant-ここに自分のカギ
5 ⌘ + S で保存して閉じる

最後に OPS を一回閉じて開き直す

貼り付けただけでは OPS は気づきません。一度止めて再起動が必要です。

ターミナルに貼って Enter 
lsof -ti:3000 | xargs kill -9 2>/dev/null
cd ~/Desktop/ARTISTORY\ BASE/ViVi/ViVi-Club/Sales/platinum-launch/pm/dashboard
npm run dev
これで完了です:
  • ターミナルに ✓ Ready in 3s のような表示が出る
  • ブラウザで OPS の localhost:3000/platinum-launch/preview を開いて「LINE ナーチャリング」を選ぶ
  • 20〜40 秒くらい待つと、LINE 本文がチャットの吹き出しに出てくる
🔐 (おまけ) 1Password を使っている人へ
🔐 カギを安全に保管しておく 推奨

複数の AI ツールを使う予定があるなら、1Password の Automation という棚にカギを 1 つ保管しておくと、毎回コピペせずに済んで便利です。

1 1Password アプリを開く → 左のリストで Automation を選ぶ
2 右上 + 新規アイテム → API クレデンシャル
3 タイトル: Anthropic-API / credential の欄に sk-ant-... を貼って保存

※ 使っていなければ気にせず Step 5 の方法で OK です。

🛠️ 困ったとき
⚠️ プレビューに「ANTHROPIC_API_KEY が設定されていません」と出る よくある

カギの貼り付け or OPS の再起動 がまだ済んでいません。Step 5 をもう一度実行してください。再起動を忘れているケースが大半です。

🚫 「invalid_api_key」「401」と出る カギ間違い

カギの貼り付け時に空白や改行が混ざっている可能性。Step 4 でもう一度キーをコピーし直して、Step 5 の貼り付けをやり直してください。カギは必ず sk-ant-api03- から始まります。

💸 「credit_balance_too_low」と出る チャージ切れ

残高がゼロになりました。Billing 画面 を開いて、もう一度 $5 チャージするだけで復活します。Auto reload を ON にしておくと次から止まりません。

😱 カギを誰かに見られた / リークが心配 緊急

API keys 画面 を開く → 該当のカギの ⋮ → Revoke ですぐに無効化できます。その後 Step 4 から新しいカギを作り直してください。

🔄 貼ったのに変わらない 再起動忘れ

OPS は起動した瞬間だけカギを読みます。"最後に OPS を一回閉じて開き直す"のコマンドをもう一度実行してください (Step 5 の最後)。

✓

これでカギの設定は完了です

OPS ダッシュボードに戻って、プレビュー画面の「LINE ナーチャリング」を開いてください。20〜40 秒で AI が文章を書き始めます。
