LINE 公式アカウント取得ガイド

LINE 公式アカウント
を立ち上げる

ナーチャリング Bot を稼働させるために必要な「LINE 公式アカウント」と 3 つのカギを取得します。

⏱️ 約 30 分 💴 無料 (月 200 通までは無料) 📱 LINE アプリ必須
💡
なぜこれが必要?

ViVi Club の「LINE ナーチャリング Bot」は、お客さんが LINE で友だち追加した瞬間からウェビナー前後の 24 通のメッセージを自動で送ります。 そのためには、お客さんが追加する LINE 公式アカウント と、その公式アカウントを Bot が操作するための 3 つのカギ が必要です。

このページは LINE 公式アカウント を ゼロから作って、カギを取り出して、1Password に保管するまでを案内します。

⚡ 全体の流れ (5 ステップ)
📱
1. 公式アカウント開設LINE 公式アカウント Manager で無料作成
 ⚙️
2. Messaging API を有効化Bot 操作の許可をオンにする
 🔑
3. 3 つのカギを取得Access Token / Secret / Channel ID
 🖼️
4. リッチメニュー登録3 状態のメニュー画像を upload
 🔐
5. 1Password に保存取得した値をすべて Automation vault へ
📚

用語整理: 「LINE 公式アカウント」 = お客さんが友だち追加する窓口 (UI 名は LINE@ → LINE 公式アカウント) / 「Messaging API channel」 = その公式アカウントを Bot が操作する仕組み / 「Provider」 = channel をまとめる "会社単位" のフォルダ

📋 詳しいやり方
1
📱

LINE 公式アカウントを開設する

下のボタンで LINE 公式アカウント Manager を開きます。普段使っている 個人の LINE アカウント でログインします。

💬
manager.line.biz を開く LINE 公式アカウント Manager (無料)
開く →

画面の流れ:

1 LINE Business ID で "LINE アカウントでログイン"
2 QR コードが出たら、スマホの LINE アプリで読み取る → 個人 LINE で承認
3 初回は "アカウント作成" → 必要情報を入力:
  • アカウント名: ViVi Club
  • メールアドレス: 自分の連絡先
  • 会社・事業者の所在地・業種: 「健康・美容」「個人」など実情に合わせて
4 「アカウント作成」ボタン → 開設完了
完了の合図:
  • Manager のホーム画面に「ViVi Club」アカウントが表示される
  • 左メニューに「ホーム / トーク / 配信 / 設定」が並ぶ
2
⚙️

Messaging API を有効にする

作ったばかりの公式アカウントは「人間が手で運用するモード」になっています。これを「Bot で自動運用するモード」に切り替えます。

画面の流れ:

1 右上の 歯車アイコン (設定) をクリック
2 左メニュー "Messaging API" を選択
3 「Messaging API を利用する」を "利用する" ボタンで有効化
4 Provider 選択画面が出る → "新規プロバイダー作成" → 名前: ViVi Club (= ブランド名でOK)
5 プライバシーポリシー・利用規約 URL は後から設定可能なので空欄でOK。「OK」
完了の合図:
  • 画面に Channel ID / Channel Secret が表示される
  • 「応答メッセージ」が「無効」、「Webhook」が「有効」になっていることを確認 (Bot 駆動の前提)
うっかり注意: 「あいさつメッセージ」「応答メッセージ」が 有効 のままだと、Bot が送るメッセージと喧嘩します。Step 5 デプロイ前に必ず両方とも 無効 に設定してください。
3
🔑

3 つのカギを取得する

Bot から LINE を操作するための 3 つの値 を取り出します。LINE Developers Console (別サイト) でしか取得できない値もあります。

🛠️
developers.line.biz/console を開く 同じ LINE アカウントでログイン
開く →

🅰️ Channel Access Token (長期)

1 Provider ViVi Club → channel ViVi Club をクリック
2 上部タブ "Messaging API設定" をクリック
3 下までスクロール → "チャネルアクセストークン (長期)" の "発行" ボタン
4 長い文字列が表示される → コピーしてメモ帳に一旦保管。これが LINE_CHANNEL_ACCESS_TOKEN

🅱️ Channel Secret

1 同じ channel ページの上部タブ "チャネル基本設定"
2 "チャネルシークレット" の値をコピー (32 文字の英数字)。これが LINE_CHANNEL_SECRET

🅲 Channel ID

1 同じ「チャネル基本設定」の一番上 "チャネルID" をコピー (10桁の数字)。これが LINE_CHANNEL_ID
⚠️ 3 つ揃っているか確認:
  • LINE_CHANNEL_ACCESS_TOKEN: 長い文字列 (200 文字以上)
  • LINE_CHANNEL_SECRET: 32 文字
  • LINE_CHANNEL_ID: 10 桁の数字
全部揃ったら次へ。
4
🖼️

リッチメニュー画像を登録する

LINE トーク画面の下に出る 固定メニュー です。ViVi Club は状況に応じて 3 種類のメニューを切り替えます (ウェビナー前 / 参加後 / 不参加)。

画像は既に assets/nurture/output/rm-{default,attended,noshow}.png に書き出し済みです (2500×1686 LINE 規格)。

LINE 公式アカウント Manager (Step 1 のサイト) で:

1 左メニュー "トークルーム管理" → "リッチメニュー"
2 "作成" ボタン → 3 つ作成:
  • ① ViVi - default (PRE-WEBINAR) → rm-default.png を upload
  • ② ViVi - attended (POST-WEBINAR) → rm-attended.png
  • ③ ViVi - noshow (REPLAY) → rm-noshow.png
3 各メニューの "アクション設定" でクリック領域を設定 (詳細は scenario.md 参照、Bot が自動で割り当てるので最低限の URL でOK)
4 3 つ作成後、それぞれの "リッチメニューID" (= richmenu-xxx...) をコピー
取得する 3 つの値:
  • LINE_RICH_MENU_AWARENESS (= default の ID)
  • LINE_RICH_MENU_CLOSING (= attended の ID)
  • LINE_RICH_MENU_CONSIDERATION (= noshow の ID)
面倒なら後回し可: リッチメニュー無しでも Bot は動きます。先に Step 5 → 配信開始 → 後でメニュー追加でもOKです。
5
🔐

取得した値を 1Password に保管する

Bot は 1Password の Automation vault から自動で値を読みに来ます。ここに正しい名前で保管すれば、私 (Claude) がそのままデプロイできます。

1Password アプリで:

1 Vaults → Automation → 右上 + New Item → API Credential
2 Title: LINE-OA-ViVi-Club (← この名前が必須)
3 下記 6 つのフィールド を追加して、Step 3-4 で取得した値を貼る (フィールド名はそのままコピー):
LINE_CHANNEL_ACCESS_TOKEN
LINE_CHANNEL_SECRET
LINE_CHANNEL_ID
LINE_RICH_MENU_AWARENESS
LINE_RICH_MENU_CLOSING
LINE_RICH_MENU_CONSIDERATION
4 Save で保存
これで完了です。
  • 1Password の Automation vault に LINE-OA-ViVi-Club アイテムができている
  • Claude に「Bot をデプロイして」と伝えれば、ここから値を読み取って Cloudflare Workers にデプロイ + LINE Webhook URL までセットアップします
🛠️ 困ったとき
📵 LINE Business ID でログインできない よくある

普段使っている LINE アプリで QR コードを読み取ってください。パソコンで開いた QR コードを スマホ LINE のカメラ で読む流れです。LINE 内蔵カメラからのみ動作します (一般カメラ不可)。

🔄 「応答メッセージ」が勝手に送られる 設定漏れ

LINE 公式アカウント Manager → 応答設定 → 「あいさつメッセージ」「応答メッセージ」を 無効 に。Webhook を「有効」に。Bot がメッセージ送信を担当する設計なので、LINE 標準の自動返信は OFF が必須です。

💸 配信数の制限が気になる 料金

LINE 公式アカウントの無料枠は 月 200 通まで。Bot のナーチャリングは 1 人あたり 24 通なので、最初の数名でテストする分には十分。本格運用が見えてきたら「ライト ¥5,000/月 (5,000通)」or「スタンダード ¥15,000/月 (30,000通)」へ。

🆔 Provider と Channel の違いがわからない 用語

Provider = 会社や個人事業者単位の「箱」(複数の Channel をまとめる)。Channel = 実際の公式アカウント+Bot 連携の「窓口」。普通は Provider 1 つの中に Channel 1 つ。

🙈 Channel Secret を失くした 緊急

LINE Developers Console → 該当 channel → "チャネル基本設定" → "再発行" ボタン。旧 secret は即無効化されるので、1Password の値も更新が必要です。

✓

これで Bot デプロイ準備 完了

Claude に「LINE Bot をデプロイして」と伝えれば、ここから後は全自動です。
Cloudflare Workers + D1 へのデプロイ + LINE Webhook URL 登録までやります。
